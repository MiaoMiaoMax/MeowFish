# MeowFish

_Minecraft Bedrock 自动钓鱼_

[English](./README.md) | 简体中文 | [繁體中文](./README.zh-TW.md)

MeowFish 是一款适用于 Minecraft 基岩版的自动钓鱼行为包，提供自动钓鱼、鱼竿耐久保护、战利品筛选、运行状态监控等功能。

## 当前版本

**v1.0.0**

## 兼容性

- 最低支持 Minecraft 版本：**1.21.120**
- 依赖：
  - `@minecraft/server` 2.3.0
  - `@minecraft/server-ui` 2.0.0
- 成就兼容性：除 1.26.50 和 1.26.51 外，其他受支持的游戏版本均兼容成就。

## 安装与使用

1. 下载 MeowFish 行为包并导入 Minecraft。
2. 在世界的「行为包」设置中启用 MeowFish。
3. 手持钓鱼竿并在潜行状态下抛竿，即可启动自动钓鱼。
4. 如需打开个人设置菜单，请将一张纸重命名为以下任意名称：
   - `MF设置`
   - `MF設置`
   - `MFSetting`

   PC 端对纸张右键，移动端长按纸张即可打开菜单。

## 功能介绍

### 自动钓鱼与基础设置

个人设置菜单提供以下选项：

- **语言：** 支持简体中文、繁体中文和英文。
- **强制自动钓鱼：** 无需玩家潜行即可启动自动钓鱼。
- **耐久保护：** 在钓鱼过程中保护鱼竿耐久。
- **自动替换鱼竿：** 当前鱼竿耐久耗尽时，自动在背包中寻找其他可用鱼竿。
- **减少浮漂下沉：** 减少浮漂下沉，以帮助避免与其他实体产生干扰。
- **欢迎提示：** 控制玩家进入世界时是否显示使用提示。
- **战利品生成方式：** 可选择原版风格（战利品从浮漂飞向玩家）、在玩家位置生成，或在浮漂位置生成。
- **粒子效果：** 可选择关闭、简约、普通和华丽粒子效果。华丽选项可由管理员控制。
- **音量：** 调整鱼咬钩提示音的音量。

### 战利品筛选

管理员启用战利品筛选功能后，玩家可以在高级设置中使用该功能。

- 支持白名单和黑名单模式。
- 可以为每种物品单独设置筛选规则。
- 筛选界面显示物品图标。
- 提供个人开关，可自行启用或关闭筛选功能。

### 高级设置与管理功能

- **恢复默认设置：** 重置个人设置。
- **管理员入口：** 验证管理员密钥后进入管理中心。
- **运行状态监控：** 查看当前正在使用自动钓鱼的玩家及其状态。
- **性能与缓存监控：** 查看状态缓存和速度缓存的命中率及检查次数。
- **最近问题：** 查看近期记录的运行问题。
- **全局控制：** 管理员可以暂停或恢复全局自动钓鱼，并管理正在运行的玩家会话。

## 战利品系统

MeowFish 使用内置的原版钓鱼战利品表和独立掷表引擎计算奖励。内置数据涵盖普通钓鱼和丛林钓鱼战利品表，包括鱼类、垃圾和宝藏子表。

同时支持生物群系标签匹配，并提供战利品表加载为空或加载失败时的诊断日志。

内置战利品数据减少了对运行时查询原版战利品表的依赖。对模组自定义战利品表的兼容性取决于其数据结构和物品定义。

## 管理员配置

行为包中的 `scripts/SystemSettings.js` 文件提供全局配置选项，包括默认行为、语言、战利品筛选、粒子效果、熔断器和调试日志等。

修改配置前，请先阅读各选项对应的注释。

修改完成后：

- **单人游戏：** 在已启用作弊的世界中，可执行 `/reload` 重新加载脚本。如果世界未启用作弊，请退出并重新载入单人游戏。
- **服务器：** 可在服务器后台控制台输入 `reload`，重新加载脚本。

日常游玩时，建议保持调试模式关闭。
