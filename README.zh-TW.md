# MeowFish

_Minecraft Bedrock 自動釣魚_

[English](./README.md) | [简体中文](./README.zh-CN.md) | 繁體中文

MeowFish 是一款適用於 Minecraft 基岩版的自動釣魚行為包，提供自動釣魚、魚竿耐久保護、戰利品篩選、執行狀態監控等功能。

## 目前版本

**v1.0.0**

## 相容性

- 最低支援 Minecraft 版本：**1.21.120**
- 相依套件：
  - `@minecraft/server` 2.3.0
  - `@minecraft/server-ui` 2.0.0
- 成就相容性：除 1.26.50 和 1.26.51 外，其他受支援的遊戲版本均相容成就。

## 安裝與使用

1. 下載 MeowFish 行為包並匯入 Minecraft。
2. 在世界的「行為包」設定中啟用 MeowFish。
3. 手持釣魚竿並在潛行狀態下拋竿，即可啟動自動釣魚。
4. 如需開啟個人設定選單，請將一張紙重新命名為以下任一名稱：
   - `MF设置`
   - `MF設置`
   - `MFSetting`

   PC 版對紙張按右鍵，行動裝置長按紙張即可開啟選單。

## 功能介紹

### 自動釣魚與基本設定

個人設定選單提供以下選項：

- **語言：** 支援簡體中文、繁體中文和英文。
- **強制自動釣魚：** 無需玩家潛行即可啟動自動釣魚。
- **耐久保護：** 在釣魚過程中保護魚竿耐久度。
- **自動替換魚竿：** 目前魚竿耐久耗盡時，自動在背包中尋找其他可用魚竿。
- **減少浮標下沉：** 減少浮標下沉，以協助避免與其他實體產生干擾。
- **歡迎提示：** 控制玩家進入世界時是否顯示使用提示。
- **戰利品生成方式：** 可選擇原版風格（戰利品從浮標飛向玩家）、在玩家位置生成，或在浮標位置生成。
- **粒子效果：** 可選擇關閉、簡約、普通和華麗粒子效果。華麗選項可由管理員控制。
- **音量：** 調整魚咬鉤提示音的音量。

### 戰利品篩選

管理員啟用戰利品篩選功能後，玩家可以在進階設定中使用此功能。

- 支援白名單和黑名單模式。
- 可以為每種物品單獨設定篩選規則。
- 篩選介面顯示物品圖示。
- 提供個人開關，可自行啟用或關閉篩選功能。

### 進階設定與管理功能

- **恢復預設設定：** 重設個人設定。
- **管理員入口：** 驗證管理員密鑰後進入管理中心。
- **執行狀態監控：** 查看目前正在使用自動釣魚的玩家及其狀態。
- **效能與快取監控：** 查看狀態快取和速度快取的命中率及檢查次數。
- **最近問題：** 查看近期記錄的執行問題。
- **全域控制：** 管理員可以暫停或恢復全域自動釣魚，並管理正在執行的玩家工作階段。

## 戰利品系統

MeowFish 使用內建的原版釣魚戰利品表和獨立擲表引擎計算獎勵。內建資料涵蓋一般釣魚和叢林釣魚戰利品表，包括魚類、垃圾和寶藏子表。

同時支援生態域標籤匹配，並提供戰利品表載入為空或載入失敗時的診斷日誌。

內建戰利品資料減少了對執行時期查詢原版戰利品表的依賴。對模組自訂戰利品表的相容性取決於其資料結構和物品定義。

## 管理員設定

行為包中的 `scripts/SystemSettings.js` 檔案提供全域設定選項，包括預設行為、語言、戰利品篩選、粒子效果、熔斷器和除錯日誌等。

修改設定前，請先閱讀各選項對應的註解。

修改完成後：

- **單人遊戲：** 在已啟用作弊的世界中，可執行 `/reload` 重新載入腳本。如果世界未啟用作弊，請退出並重新載入單人遊戲。
- **伺服器：** 可在伺服器後台控制台輸入 `reload`，重新載入腳本。

日常遊玩時，建議保持除錯模式關閉。
